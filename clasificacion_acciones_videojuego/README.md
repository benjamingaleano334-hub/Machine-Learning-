# Clasificacion de Acciones de Usuarios en una Plataforma de Videojuegos

## Descripcion
Trabajo practico sobre clasificacion de acciones de usuarios utilizando reglas simples de tipo si-entonces implementadas en Python

## Objetivos 
- Comprender el uso del aprendizaje supervisado
- Identificar patrones de comportamiento
- Aplicar reglas simples para clasificar acciones

## Contenido
`clasificacion_acciones.ipynb`:
Desarrollo completo de la actividad, incluyendo los datos, reglas, implementacion, resultados y reflexion.

## Tecnologias utilizados
- Python
- Pandas
- Jupyter Notebook
