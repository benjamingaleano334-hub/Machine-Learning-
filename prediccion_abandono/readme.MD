Prediccion de abandono en estudiantes de terciarios

Descripción

Este proyecto fue realizado como parte de un trabajo práctico de la facultad. Su objetivo es aplicar los conocimientos adquiridos durante la cursada para resolver el problema planteado.

Objetivos

- Aplicar los conceptos teóricos vistos en clase.
- Desarrollar una solución al problema propuesto.
- Organizar y documentar el trabajo realizado.

Tecnologías utilizadas

- Python
- Jupyter Notebook
- GitHub

Desarrollo

El trabajo se encuentra desarrollado en el archivo "Tp_abandon.ipynb", donde se incluyen el código, los procedimientos utilizados y los resultados obtenidos.

Como ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir el archivo "TP_abandon.ipynb" con Jupyter Notebook o Google Colab.
3. Ejecutar las celdas en orden para visualizar el desarrollo del trabajo.
